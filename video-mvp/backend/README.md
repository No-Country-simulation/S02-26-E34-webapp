# Backend - MVP Conversor Video

Este es el backend del proyecto, desarrollado con FastAPI y gestionado mediante `uv`.

## 🚀 Inicio Rápido con `uv`

Asegúrate de tener instalado [uv](https://astral.sh/uv/).

### Instalación de dependencias
```bash
uv sync
```

### Ejecución del servidor
```bash
uv run python main.py
```

### Gestión de paquetes
- **Añadir un paquete:** `uv add nombre-paquete`
- **Eliminar un paquete:** `uv remove nombre-paquete`
- **Actualizar entorno:** `uv sync`

## 🛠️ Tecnologías
- FastAPI
- Celery + Redis
- PostgreSQL + SQLAlchemy
- YOLOv8 & OpenCV
- Whisper (OpenAI)
